# Погода — прогноз рядом

Небольшое адаптивное приложение о погоде на чистом JavaScript. Ищет города по всему миру и показывает текущие условия, влажность, ветер, ощущаемую температуру и прогноз на 7 дней.

## Что внутри

- `index.html` — разметка страницы.
- `style.css` — оформление и адаптация для телефона.
- `app.js` — поиск города, запросы к API и обновление интерфейса.

Данные загружаются с бесплатного [Open-Meteo](https://open-meteo.com/). Ключ API, сервер и сборщик не нужны. При первом открытии автоматически загружается Астана. Можно искать город по-русски или на другом языке; если совпадений несколько, выберите нужный вариант из списка.

## Запустить на компьютере

1. Скачайте или распакуйте папку `weather-app`.
2. Откройте файл `index.html` в браузере.
3. Если браузер ограничивает запросы при открытии через `file://`, запустите локальный сервер из этой папки:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000`.

Также можно открыть папку в VS Code и запустить её расширением Live Server.

## Опубликовать на GitHub Pages

### Вариант A: через сайт GitHub

1. Войдите на [GitHub](https://github.com/) и нажмите **New repository**.
2. Назовите репозиторий, например `weather-app`. Для учебного сайта выберите **Public** и нажмите **Create repository**.
3. Нажмите **Add file → Upload files**.
4. Загрузите **содержимое** этой папки: `index.html`, `style.css`, `app.js` и `README.md` — в корень репозитория.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите источник **Deploy from a branch**.
8. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
9. Через несколько минут адрес сайта появится на странице Pages. Для обычного репозитория вида `weather-app` адрес будет примерно таким: `https://ВАШ-ЛОГИН.github.io/weather-app/`.

### Вариант B: загрузить из терминала с помощью Git

Установите Git, откройте терминал в папке `weather-app` и выполните команды. Замените `ВАШ-ЛОГИН` на свой GitHub username, а адрес репозитория — на созданный вами:

```bash
git init
git add .
git commit -m "Создано приложение погоды"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/weather-app.git
git push -u origin main
```

Затем включите GitHub Pages по шагам 6–9 выше. В следующих обновлениях отправляйте изменения командами `git add .`, `git commit -m "Описание изменений"` и `git push`.

> GitHub Pages публикует содержимое репозитория в интернете. Не помещайте в него пароли, токены или другие секреты.

## Если что-то не работает

- Город не найден: проверьте написание или уточните страну, например «Алматы, Казахстан».
- Нет погоды: проверьте интернет и повторите поиск. Open-Meteo должен быть доступен из вашей сети.
- Вместо сайта 404: проверьте, что файл называется именно `index.html`, лежит в корне ветки `main`, а в **Settings → Pages** выбраны ветка `main` и папка `/(root)`.
- После первой публикации подождите несколько минут и обновите ссылку GitHub Pages.
